=== WeightLossAffordable ===
Version: 2.1.0
License: GPL-2.0-or-later

The single WeightLossAffordable theme preserves the existing forest/sage/ivory design system, typography, rounded card surfaces, section animations and responsive layouts. It supports Elementor pages and includes a complete WLA-styled front-page fallback.

== Recommended package ==

Install this theme together with the single `WeightLossAffordable Core + NuestraRx` plugin. The plugin bundles the original NuestraRx quiz/intake/treatment modules and WeightLossAffordable's Elementor widgets, demo importer and WLA-styled treatment/story/video/calculator components. Do not install separate NRX Core or WLA Experience plugins.

== Theme details ==

- Existing WeightLossAffordable header, footer, navigation, homepage sections, resource explorer and page templates are retained and updated with the supplied treatment-oriented demo content.
- Published NuestraRx treatment posts use a dedicated `single-nrx_treatment.php` template which renders details in the WLA design system through the bundled plugin.
- The theme's static fallback homepage uses the WLA-native hero, information cards, four-stage journey, science overview, resource library, transformation placeholders, video-story section, FAQ and CTA styling.
- Demo editorial photographs are illustrative AI-generated lifestyle images, not patient images or outcome evidence.

Elementor is optional for the theme fallback and recommended for visual section editing. Verify all demo content, media, links, accessibility and mobile layouts on staging before publication.
